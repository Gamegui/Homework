# Ключевые военные победы России — доклад

**Тема:** Ключевые военные победы России
**Требования к информации:** достоверность, актуальность
**Дата подготовки:** 24 сентября 2026

## Что в папке

- `prezentatsiya.pptx` — презентация, 11 слайдов: титул, план, 8 слайдов боёв, вывод (главный файл)
- `rech-k-prezentatsii.md` — речь к слайдам + ответы на вопросы
- `doklad.md` — полный текст доклада (7–10 минут чтения)
- `tekst-dlya-chteniya.md` — короткая версия для быстрого чтения (около 5 минут)
- `istochniki.md` — источники и проверка на достоверность / актуальность
- `plan-vystupleniya.md` — план выступления + вопросы для самопроверки

## Как пользоваться

1. Прочитай `doklad.md` — это основа.
2. На выступлении говори по `plan-vystupleniya.md`, а не читай с листа.
3. Если спросят «откуда взял?» — открывай `istochniki.md`.
